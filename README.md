# 🎤 InterviewIQ: AI Mock Interviewer

Upload your resume and a job description. InterviewIQ interviews you with tailored questions, transcribes your spoken answers, scores them, and gives you an analytics dashboard plus a PDF report.

## Features
- **Resume + JD analysis**: skill match %, matched and missing skills
- **RAG**: resume chunks embedded with sentence-transformers and indexed in FAISS, so questions reference your real projects
- **Tailored questions**: technical, behavioral (STAR) and HR, generated by an LLM
- **Voice answers**: local speech-to-text with faster-whisper
- **AI scoring**: clarity, relevance, depth and STAR structure (1-10) with feedback and a stronger-answer hint
- **Dashboard**: score trend, skill radar, filler-word counter, skill-gap chart (Plotly)
- **PDF export** of the full feedback report
- **LLM-agnostic**: Google Gemini (free) or Ollama (fully offline)

## Architecture
```
Resume PDF + JD ─► resume_parser (pypdf, skill gap, FAISS RAG)
                       │
                       ▼
                 question_gen (LLM) ─► Streamlit interview UI ◄─ speech.py (Whisper)
                                              │
                                              ▼
                                       scorer (LLM + heuristics)
                                              │
                                              ▼
                              analytics (Plotly dashboard + PDF)
```

## Quick start (Windows)
```
setup.bat          :: creates venv, installs packages, creates .env
:: open .env and paste your GEMINI_API_KEY
run.bat            :: starts the app at http://localhost:8501
```

### Manual
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
streamlit run app.py
```

### Fully offline (no API key)
Install [Ollama](https://ollama.com), run `ollama pull llama3.2`, then set `LLM_PROVIDER=ollama` in `.env`.

## Deploy free
Push to GitHub, then on [Streamlit Community Cloud](https://streamlit.io/cloud) choose the repo and add `GEMINI_API_KEY` under **Secrets**. Whisper and sentence-transformers are heavy, so for the hosted demo keep `WHISPER_MODEL=tiny`.
